# Reference inputs (not publicly served)

This directory stores design and research provenance outside `public/`. The currently available PRD, Stitch export, design specification, and full logo are mirrored here. Missing authoritative files are listed in `docs/source-map.md`.

- `brand/`: original brand assets.
- `stitch/`: original ZIP (when supplied) and extracted export.
- `research/`: canonical questionnaire, consent, and de-identified/appropriately protected historical data.
- `legacy/`: Python scoring source, fixtures, feedback, and representative output.
- `CyberAwareGaza_PRD_v2.0.txt`: byte-for-byte copy of the supplied PRD attachment.
- `source-manifest.json`: reproducible Phase 0 provenance, sizes, hashes, and permitted-use classifications.

Do not place identifiable raw response data in the application repository without an approved handling decision.
